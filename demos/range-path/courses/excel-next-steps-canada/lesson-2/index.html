Create a table

First type a small list with a header row, the way you already can from Excel basics. Then turn that list into a table.

Microsoft’s steps to create a table quickly:

  1. Select the cell or the range that holds your data.
  2. Select Home > Format as Table.
  3. Pick a table style.
  4. In the Format as Table dialog box, select the checkbox My table as headers if you want the first row to be the header row, then click OK.

After you click OK, Excel formats the range as a table. You should see header arrows and, usually, banded rows.

If your first row is labels such as Item and Amount, keep My table as headers selected so those words stay labels, not data. If you forget, the first row of numbers may be treated as a header.

Practise with sample rows only — for example, a pretend list of hall-rental supplies. Do not use another person’s private spreadsheet.

If you cannot find Format as Table, look on the Home tab. Some versions also let you create a table from the Insert tab; this lesson follows Microsoft’s Home > Format as Table steps.
