Make a chart from your data

Microsoft says charts help you visualize data in a way that can have a clear impact. A chart turns numbers into a picture, such as columns or slices, so a group can see a pattern faster than by reading every cell.

To create a chart (Microsoft’s Windows steps):

  1. Select the data for the chart, including the header labels if you have them.
  2. Select Insert > Recommended Charts.
  3. Select a chart on the Recommended Charts tab to preview it.
  4. If you do not see one you like, select the All Charts tab to see more types.
  5. Select a chart, then select OK.

Microsoft notes that you can also select data and press Alt+F1 to create a chart right away, but it might not be the best type for your data. Recommended Charts is the safer first choice.

Keep the chart simple. One small table of sample categories and amounts is enough. After the chart appears, you can click it and add a title if your version shows that option. You do not need trendlines, 3-D pie effects, or advanced formatting for this course.

If the numbers in the table change, many charts update when the selected data changes. Check that you selected the right cells before you insert the chart.
