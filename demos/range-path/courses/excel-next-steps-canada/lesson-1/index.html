What is an Excel table?

The Excel basics course showed you cells, simple formulas, AutoSum (SUM), and how to save. This course adds three next steps: tables, charts, and a few more functions.

Microsoft says that to make managing and analyzing a group of related data easier, you can turn a range of cells into an Excel table (once also called an Excel list). Do not confuse this with the separate “data tables” used for what-if analysis. This course uses the everyday table you create from a list.

A table can include:

  • A header row. By default a table has one. Each column header has filtering turned on so you can filter or sort quickly.
  • Banded rows (alternate shading) to help you see the lines.
  • A total row you can add later, with a drop-down list of functions such as SUM and AVERAGE.
  • A sizing handle in the lower-right corner so you can drag the table larger.

You can create more than one table on a sheet. Use a clear header row, such as Item, Quantity, and Amount, and sample numbers only.

This is not tax or bookkeeping advice. Keep real payroll or client files out of class practise.
