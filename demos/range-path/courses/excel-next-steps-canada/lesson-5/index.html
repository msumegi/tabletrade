AVERAGE, MIN, MAX, and COUNT

You already know that a formula starts with = and that SUM adds numbers. These four functions answer other everyday questions.

AVERAGE returns the average (the arithmetic mean) of its arguments. Microsoft’s example: if A1:A20 contains numbers, =AVERAGE(A1:A20) returns the average of those numbers. You can also use a shorter range, such as =AVERAGE(B2:B6).

MIN returns the smallest number in a set of values. Example: =MIN(B2:B6).

MAX returns the largest value in a set of values. Example: =MAX(B2:B6).

COUNT counts how many cells contain numbers. Microsoft’s example: =COUNT(A1:A20). Empty cells and most text are not counted. If you need to count text as well, Microsoft points to other functions such as COUNTA; this lesson stays with COUNT.

Type the formula in an empty cell next to or below your sample list, then press Enter. If the result looks wrong, click the cell and check the range in the formula bar.

You can use the same functions on a total row (Lesson 3) or by typing them yourself. Use sample volunteer hours or supply amounts — not real payroll.
