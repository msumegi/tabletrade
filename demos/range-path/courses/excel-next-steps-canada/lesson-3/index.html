Lesson 3 of 5

Sort, filter, and a total row

Once your list is a table, you can work with it faster.

Microsoft says every table column has filtering enabled in the header row so you can filter or sort quickly. Click the small arrow on a header.

  • Sort changes the order, such as A to Z or smallest to largest.
  • Filter hides rows that do not match what you chose, such as showing only one item name.

The hidden rows are still in the file. Clearing the filter brings them back. Try this on sample data so you can see the difference.

You can also add a total row. Microsoft says that once you add a total row, Excel gives you an AutoSum drop-down list with functions such as SUM and AVERAGE. When you pick one, the table converts it to a SUBTOTAL function that, by default, ignores rows hidden by a filter.

You already used SUM in Excel basics. Here, the useful new idea is that the total row can show an average as well as a sum, and that a filtered table’s total can ignore hidden rows.

You do not need to write the SUBTOTAL formula by hand for this lesson. Use the drop-down on the total row.

If you resize the table, Microsoft describes a sizing handle in the lower-right corner.
