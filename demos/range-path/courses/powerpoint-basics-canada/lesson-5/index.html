Save and show your slides

Save often so you do not lose your work.

To save (Microsoft’s Windows steps):

  1. On the File tab, choose Save.
  2. Pick or browse to a folder.
  3. In the File name box, type a name, then choose Save.

Microsoft also says to press Ctrl+S often, or save the file to OneDrive and let AutoSave help. AutoSave is not a reason to skip saving yourself if you are working on a computer that does not use it. In PowerPoint for the web, Microsoft says work is saved automatically to OneDrive; you can click the file name in the title bar to rename it.

A clear name helps later, such as soup-lunch-slides or volunteer-orientation-practise.

To give your presentation:

  • On the Slide Show tab, click From Beginning to start at the first slide.
  • Click From Current Slide if you want to start from the slide you are on.

To move through the slides, Microsoft says you can click the mouse or press the spacebar. Arrow keys can also move forward and back. To leave Slide Show view at any time, press Esc. You return to the editing view.

This course does not require presenting online or broadcasting to a remote audience. Practise once with Esc so you know how to leave full screen.

Finishing this course does not make you a MOS-certified presenter.
