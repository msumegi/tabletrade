What is PowerPoint, and how do you start?

Microsoft PowerPoint is a program for slide shows. Microsoft’s basic-tasks guide says that to convey a message or a story, you break it down into slides. Think of each slide as a blank canvas for the pictures and words that help you tell your story.

When you open PowerPoint, you will see some built-in themes and templates. Microsoft says a theme is a slide design that contains matching colours, fonts, and special effects such as shadows and reflections.

To start with a theme (Microsoft’s Windows steps):

  1. On the File tab of the Ribbon, select New, and then choose a theme. PowerPoint shows a preview, with colour variations on the right.
  2. Click Create, or pick a colour variation and then click Create.

In PowerPoint for the web, Microsoft says you can select Browse templates to choose a theme.

People in Canada use slides for many everyday jobs: a short talk at a community hall, a volunteer orientation, or a simple update at work. This course uses Canadian spelling in the lesson text. On the screen, some buttons may still say “Color” because that is how the software is labelled.

This course is not a design diploma and not a MOS exam. If PowerPoint is not on the computer in front of you, ask your adult learning council which version they have. Do not buy software because this lesson mentioned it.
