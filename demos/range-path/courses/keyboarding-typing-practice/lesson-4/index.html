A few official keyboard shortcuts

Microsoft says keyboard shortcuts are keys or combinations of keys that provide an alternative way to do something you would typically do with a mouse. Learning a few of them can make typing and editing faster. The behaviour of some shortcuts may vary in different applications, and some applications may change them. The list below uses the default Windows shortcuts from Microsoft’s official page.

Text-editing shortcuts you can practise:

  • Ctrl + C (or Ctrl + Insert) — copy the selected text.
  • Ctrl + X — cut the selected text.
  • Ctrl + V (or Shift + Insert) — paste.
  • Ctrl + Z — undo the last typing (or undo the previous action).
  • Ctrl + Y — redo typing that was undone with Ctrl + Z.
  • Ctrl + A — select all text (or select all items in a window).

Other useful shortcuts from the same official pages:

  • Alt + Tab — switch between open windows. Hold Alt and press Tab more than once to cycle through them.
  • Windows key — open or close the Start menu.
  • Windows key + I — open Settings.
  • Windows key + U — open Accessibility settings (Windows 11) or the Ease of Access area (older wording on the same help family).

Practise with a short paragraph you typed in Lesson 2. Select a sentence, copy it, paste it, then undo if you need to. If holding two keys at once is hard, use Sticky Keys from Lesson 3.

You do not need to memorise Microsoft’s full list. Choose a few you will actually use this week.
