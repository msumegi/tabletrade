Make the keyboard easier to use

Windows includes built-in settings that can make a keyboard easier to use. You do not have to buy extra software for these tools. Microsoft’s help page explains how to find them.

On Windows 11, press the Windows logo key + U, or select Start > Settings > Accessibility, then select Keyboard. On Windows 10, select Start > Settings > Ease of Access > Keyboard.

Microsoft lists these options:

  • Sticky Keys — turn this on if you have trouble pressing two keys at the same time. Sticky Keys let you press commands that use multiple keys (such as Ctrl + S) one key at a time.
  • Toggle Keys — play a sound whenever you press Caps lock, Num lock, or Scroll lock. That sound can tell you if you turned capitals on by accident.
  • Filter Keys — set the sensitivity of the keyboard so it can ignore brief or repeated keystrokes. This can help if a key repeats when you only meant to press it once.
  • On-screen keyboard — select keys with a mouse or another pointing device. Lesson 5 covers this in more detail.

You can also turn on a setting that underlines access keys when they are available, or use the Print Screen key to open screen snipping.

Try one change at a time so you can tell what helped. If a setting does not suit you, turn it off again on the same screen.

If you use a different operating system, look in that system’s Settings or Accessibility help. Do not guess at another computer’s click steps from this Windows page.
