Lesson 5 of 5

Type with built-in help, then keep your skills current

Windows has a built-in Accessibility tool called the On-Screen Keyboard (OSK). Microsoft says you can use it instead of a physical keyboard. You do not need a touchscreen. The OSK shows a visual keyboard with the standard keys, and you can use a mouse or another pointing device to select keys.

To open it on Windows 11, go to Start > Settings > Accessibility > Keyboard, and turn on the On-Screen Keyboard switch. On Windows 10, use Start > Settings > Ease of Access > Keyboard and turn on Use the On-Screen Keyboard. Microsoft also says you can press the Windows logo key + Ctrl + O to turn it on. From the sign-in screen, select the Accessibility (or Ease of Access) button in the lower-right corner, then select On-Screen Keyboard.

The keyboard stays on the screen until you close it. An Options key lets you hear a click, show a numeric keypad, click keys, hover over keys, or scan through keys. You do not have to use every option.

The same Accessibility settings can make the text cursor thicker or add a colourful indicator, and can make the mouse pointer larger or a different colour if that helps you see where you are.

Skills for Success Digital also says to keep digital tools up to date, for example by downloading updates, and to update and upgrade digital skills by using what you already know to learn the next skill you need.
