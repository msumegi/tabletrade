Start Word and look around

Microsoft Word is a program for writing documents: letters, lists, resumes, notes, and workplace forms. Microsoft’s guide for new users walks through how to start the program, find the main parts of the window, save your work, and format text.

To start Word on a Windows computer (Microsoft’s steps):

  1. Click the Start button, or press the Windows key, to open the Start menu.
  2. Find Word in the list of applications and click it.

The first time you start Word, a licence agreement might appear. Follow the on-screen choices with help from a tutor if you need it.

Useful parts of the window (from Microsoft’s tour):

  • The title bar shows the file name and the Word name, plus minimize, restore, and close.
  • The Quick Access Toolbar holds frequent commands such as Save, Undo, and Redo.
  • The File tab has commands that act on the whole document: New, Open, Save As, Print, and Close.
  • The ribbon holds the tools you use while writing. The Home tab is where you will find most text formatting.
  • The large white area is the edit window, where you type.
  • A scroll bar moves the page, and a zoom control changes how large the page looks.

To quit Word, click the X in the upper-right corner. If you changed the document since the last save, Word asks if you want to save. Click Yes to save, No to quit without saving, or Cancel if you clicked X by mistake.
