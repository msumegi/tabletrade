Type, select, undo, and redo

Question 1 of 7

  1. Before you format or replace a group of words, you should:

    Select first (Microsoft).

  2. Press Enter when you want to:

    Enter starts a new paragraph; Word wraps lines.

  3. An official way to undo is:

    Ctrl+Z or the Undo button.

  4. Microsoft says you cannot undo:

    File-tab commands and saving cannot be undone.

  5. Redo appears when:

    Redo shows after an undo.

  6. True or false: You should type your SIN into a shared practice file so Word can check it.

    Do not type private numbers into practice files.

  7. Zoom is useful when:

    Zoom changes the view only.
