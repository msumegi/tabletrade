Check spelling the Canadian way

This course uses Canadian spelling, such as centre, colour, cheque, and favour. Word can check spelling, but only in the language it is set to use.

Microsoft says you can manage the languages that check spelling and grammar.

For selected text:

  1. Select the words (or click in the paragraph).
  2. Go to the Review tab.
  3. Choose Language, then Set Proofing Language.
  4. Choose the language you want Word to use for that text.

Microsoft notes that languages already in use appear at the top of the list, and languages with downloaded proofing tools show a check mark. If you do not want Word to mark errors in selected text, you can choose not to check spelling or grammar for that selection.

To add a language or change the default:

  1. Go to Review > Language > Language preferences, or open File > Options > Language.
  2. Under authoring and proofing languages, you can add a language. If proofing tools are available, Microsoft shows a note such as Proofing available or Proofing installed.
  3. Follow the prompts to add the language and, if needed, get proofing tools.
  4. You can set a preferred authoring language.

Look for a Canadian English option if it appears on your computer. If you do not see it, ask a tutor — extra language or proofing tools may need to be installed.

If you write in more than one language, Microsoft describes a Detect language automatically check box under Review > Language > Set Proofing Language.

A spelling checker is a helper, not a judge. Read the suggestions before you accept them. This course is not an English-test credential.
