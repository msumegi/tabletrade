Save, open, and print

You must save a document if you want to close Word without losing your writing. Microsoft says that when you save, the document is stored as a file on your computer or on a network location. Later you can open it, change it, and print it.

To save (Microsoft):

  1. Click the Save button on the Quick Access Toolbar.
  2. If you have saved this file before, Word saves it with the same name and you are done.
  3. If this is the first save, a Save As or “Save this file” window appears. Choose a location, type a name in the File name box, and click Save.

Use a clear name, such as cover-letter-practice or thank-you-note. Many people save into Documents. Microsoft notes that files may also sit in OneDrive or another location, depending on the computer’s setup.

To open a document later:

  • Open File Explorer, go to Documents (or the folder you used), and double-click the file, or
  • In Word, click the File tab, then Open. Recently saved files may appear under Recent.

To preview and print (Microsoft):

  1. Click the File tab.
  2. Click Print to see a preview.
  3. Review the settings.
  4. When the preview looks right, click Print.

Preview first. Ask learning-centre staff which printer to use. Saving often is safer than hoping you will remember at the end of class.
