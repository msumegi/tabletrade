Margins, page numbers, and a simple header

Choose an answer, then check it. Your score stays on this device.

Question 1 of 7

  1. Word’s automatic margin, according to Microsoft, is:

    One-inch default (Microsoft).

  2. To change margins, Microsoft’s path is:

    Layout > Margins.

  3. To insert a header, start with:

    Insert > Header or Footer.

  4. To leave a header, Microsoft says you can:

    Close Header and Footer, or Esc.

  5. On Windows, Microsoft’s page-number steps include:

    Windows steps opened 10 November 2026. Other versions may say Page Number.

  6. True or false: It is fine if the only place a title appears is in the header.

    Put important titles in the body as well.

  7. Different First Page is useful when you want to:

    Microsoft: check Different First Page to eliminate a header on a title page.
