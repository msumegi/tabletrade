Word can only check the language it is set to use

About 3 minutes to read, plus a short practice.

This course uses Canadian spelling, including *centre*, *colour*, *cheque*, and *practise* as a verb / *practice* as a noun. Those are the spellings we ask you to use in practice files. Word will only mark a word as a problem in the language it is using for proofing. If Word is set to another kind of English, it may flag *centre* or *colour* as if they were mistakes — or it may miss a real typo.

Canada’s Skills for Success describe writing as including correct spelling, clear punctuation, and a review step: proofread and correct your writing for grammar and spelling. Word’s checker is a helper for that review. It is not a judge, and this course is not an English-test credential.

Microsoft says you can manage the language or languages that check spelling and grammar. You can set a language for selected text, add a language to Office, and — if you write in more than one language — turn on automatic language detection. You do not need every option today. The everyday path is: select your text (or click in the paragraph), then tell Word which language to use for proofing.

On a shared computer, change the language for your practice document rather than trying to rebuild Office for everyone. Ask a tutor before you download extra language packs. A single practice page set to the right language is enough for this lesson.

Set the proofing language for your text

About 2 minutes to read, plus a short practice.

To change the language for selected text, Microsoft’s path is Review > Language > Set Proofing Language. Languages already in use in the document appear at the top. Languages with downloaded proofing tools show a check mark. Choose the language you want Word to use for that text.

We did not find a single required menu label on the Microsoft pages opened 10 November 2026 that we can quote as “English (Canada)” word for word. Look for a Canadian English option if it appears on your computer. If you do not see it, ask a tutor — extra language or proofing tools may need to be installed.

Microsoft also says that if you do not want Word to mark errors in the selected text, you can choose Do not check spelling or grammar for that selection. That is useful for an address block or a name Word does not know. It is not a reason to turn checking off for a whole letter. After you choose a language, click OK (or the matching confirm button on your screen) and look through the page for wavy underlines. Those marks are invitations to look again, not orders to change every word.

If you write in more than one language, Microsoft describes a Detect language automatically check box under Review > Language > Set Proofing Language. If you use only one language, that step is not necessary.

Add a language, and read every suggestion

About 2 minutes to read, plus a short practice.

To add a language or change Office defaults, Microsoft describes two doors to the same neighbourhood: Review > Language > Language preferences, or File > Options > Language. Under authoring and proofing languages you can add a language. Beside a language name you may see Proofing available, Proofing installed, or Proofing not available. “Proofing installed” means the spelling and grammar tools for that language are ready. “Proofing available” means you can get a language pack; Microsoft says to select that link to go online and get it. Do that only on a computer you are allowed to change.

You can set a preferred authoring language (it appears in bold at the top of the list). Changes to the Office authoring and proofing list, Microsoft notes, are applied to other Microsoft products in your account. That is one more reason to ask before you change defaults on a shared machine.

When Word underlines a word, read the suggestion before you accept it. A checker can miss a wrong word that is still a real word (*form* instead of *from*), and it can flag a correct Canadian spelling if the language is wrong. Skills for Success includes a review step — proofread for spelling and for meaning. You are still the person who decides.

The Language Portal of Canada publishes writing tips on Canadian spelling, but those pages returned a block (HTTP 403) when we tried to open them on 10 November 2026, so this lesson does not quote them. Use the course spelling list above, and a tutor or a Canadian dictionary if you are unsure.

Worked example 1. A notice that uses *centre* and *colour*

Problem

Noah writes “community centre” and “colourful cup” in the notice file, selects the whole page, and opens Review > Language > Set Proofing Language.

Steps

  1. A Canadian English option appears, and it shows a check mark.
  2. Noah chooses it.

Result

Word no longer treats *centre* as a problem.

Worked example 2. Reading a suggestion

Problem

Noah typed “cheuqe” instead of “cheque.” Word underlines it.

Steps

  1. Noah opens the suggestion list, sees *cheque*, and accepts that one — not a different word.

Result

Noah does not accept a change that would turn a name or an address into something else.

Try it

About 2 minutes to read, plus a short practice.

  1. In your practice document, type a sentence that uses *centre*, *colour*, or *cheque*.
  2. Select the text and open Review > Language > Set Proofing Language.
  3. Choose a Canadian English option if it appears. If it does not, write down what you see and ask a tutor.
  4. If a word is underlined, read the suggestion before you accept it.
  5. Do not download language packs on a shared computer unless staff agree.

Canadian English proofing — take-home steps

  • Course spellings: centre, colour, cheque, practise (verb) / practice (noun)
  • Review > Language > Set Proofing Language
  • Look for a Canadian English option if it appears; ask if it does not
  • A check mark means proofing tools are downloaded
  • File > Options > Language or Review > Language > Language preferences to add a language
  • Proofing installed / available / not available tell you whether tools are ready
  • Read every suggestion; you are still the proofreader
