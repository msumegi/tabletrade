Cheat sheet

Sample steps only. Use the browser print dialog to save a PDF.

Lesson 1. Start Word and look around — take-home steps

  • Start: click Start or press the Windows key, then choose Word
  • Title bar shows the file name; X closes Word
  • Quick Access Toolbar: Save, Undo, Redo
  • File tab: New, Open, Save As, Print, Close
  • Ribbon (often the Home tab): tools for the words on the page
  • Zoom changes the view, not the printed size
  • If Word asks about saving, Yes saves, No discards, Cancel stays

Lesson 2. Type, select, undo, redo — take-home steps

  • Click in the edit window and type; Word wraps each line
  • Press Enter for a new paragraph, not for every line
  • Select first: drag with the left mouse button
  • Undo: Ctrl+Z or the Quick Access Toolbar (repeat to go further back)
  • Redo: Ctrl+Y or F4, or Redo on the toolbar after an undo
  • You cannot undo some File-tab actions or saving
  • Do not type passwords or SINs into a practice file

Lesson 3. Save and reopen — take-home steps

  • Save on the Quick Access Toolbar
  • First save: choose a location, type a File name, click Save
  • Later Save clicks update the same file
  • File > Save As makes a copy with a new name or folder
  • Use a clear name such as thank-you-note
  • Reopen from File Explorer > Documents, or File > Open > Recent
  • Files may live in Documents, OneDrive, or another folder

Lesson 4. Font, bold, and lists — take-home steps

  • Select the text, then use the Home tab Font group
  • Bold, Italic, Underline, Font Size, Font Color (button may say Color)
  • Clear All Formatting leaves plain text
  • Numbered list: type 1. then a space
  • Bulleted list: type * then a space, or Home > Bullets
  • Keep a list together — do not drop a plain paragraph in the middle
  • A real heading should use a style (next lesson), not only bigger bold text

Lesson 5. Heading styles — take-home steps

  • Select the heading text first
  • Home tab > Styles group > Heading 1 (More shows more styles)
  • Use Title or Subtitle for the document’s own title if that fits
  • Keep a logical order: Heading 1, then 2, then 3 — do not skip
  • A style set on the Design tab can change every styled heading at once
  • Put the real title in the body of the page, not only in a header
  • Save after you apply the style

Lesson 6. Margins, header, page numbers — take-home steps

  • Default margin is one inch; change it with Layout > Margins
  • Insert > Header or Footer, choose a style, then type short text
  • Edit a header by double-clicking it; leave with Esc or Close Header and Footer
  • Windows page numbers: double-click the header or footer, Insert > Page Numbering, Current Position, choose a style
  • Mac or web labels may say Page Number or Page Numbers
  • Do not put important facts only in the header or footer
  • Keep the real title in the body with a heading style

Lesson 7. Canadian English proofing — take-home steps

  • Course spellings: centre, colour, cheque, practise (verb) / practice (noun)
  • Review > Language > Set Proofing Language
  • Look for a Canadian English option if it appears; ask if it does not
  • A check mark means proofing tools are downloaded
  • File > Options > Language or Review > Language > Language preferences to add a language
  • Proofing installed / available / not available tell you whether tools are ready
  • Read every suggestion; you are still the proofreader

Lesson 8. Tables and alt text — take-home steps

  • Use a table only for simple data; otherwise use headings and short paragraphs
  • Insert > Table, choose a small number of columns and rows
  • Turn on Header row and type column names; press Tab to move
  • Do not merge, split, nest, or leave blank rows and columns
  • Insert a picture from the Insert tab (choices differ by version)
  • Right-click > View Alt Text, or Picture Format > Alt Text
  • Write one or two sentences, or mark the picture decorative if it has no meaning

Lesson 9. Letter or notice — take-home steps

  • Save a copy with a clear name before you edit the starter
  • Apply Heading 1 (or Title) to the real title in the body
  • Replace placeholders; do not type private numbers
  • Use a short bullet or numbered list where it helps
  • Set proofing to Canadian English if it appears; keep centre, colour, cheque, practise/practice
  • Optional: simple header, Normal margins, tiny table, picture with alt text
  • Workplace Writing and Job Search cover other kinds of writing

Lesson 10. Preview, print, and PDF — take-home steps

  • Save the Word file first
  • File > Print shows a preview; review settings before you print
  • Ask staff which printer to use, and whether to print at all
  • Windows PDF: File > Save a Copy or Save As > Browse > PDF > Save
  • Options can include Document structure tags for accessibility
  • A PDF does not guarantee the file cannot be edited
  • Keep the Word file if you may need to change the page later
