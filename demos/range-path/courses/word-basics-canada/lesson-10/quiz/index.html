Preview, print, and export a PDF

Choose an answer, then check it. Your score stays on this device.

Question 1 of 7

  1. To preview how a page will look on paper, Microsoft’s path is:

    File > Print shows a preview and then lets you print.

  2. Before you print at a learning centre, you should:

    Ask first; one copy with permission is enough.

  3. Microsoft’s Windows steps to make a PDF start with:

    Then Browse, choose PDF, and Save.

  4. After Browse, you choose:

    PDF, then Save.

  5. Sharing a file as a PDF:

    Microsoft’s important note: many programs, including Word, can edit PDFs.

  6. True or false: A paper printout replaces the need to save the Word file.

    Save the file; printing is not the same as saving.

  7. An option Microsoft mentions for a more accessible PDF is:

    Found under More Options > Options when you save as PDF.
