Format text on the Home tab

Formatting changes how text looks so a letter or notice is easier to read.

Microsoft says most text formatting tools are on the Home tab, in the Font group. First select the text, then click a button.

Useful Font-group tools Microsoft lists:

  • Font and Font Size change the typeface and size.
  • Bold makes text thicker.
  • Italic slants the text.
  • Underline draws a line under the text.
  • Font Color changes the text colour.
  • Text Highlight Color looks like a highlighter pen.
  • Clear All Formatting removes extra formatting and leaves plain text.

Use formatting for a reason. A heading might be larger and bold. Important dates can be bold. Long stretches of coloured or underlined text are harder to read.

Styles apply a ready-made look to titles and headings. Microsoft’s steps:

  1. Highlight the text.
  2. On the Home tab, in the Styles group, point at a style to preview it.
  3. Click the style you want. Use the More arrow if you need to see more styles.

You can also change the look of the whole document from the Design tab, in Document Formatting, by pointing at a style set and then clicking it.

For line and paragraph spacing, Microsoft says to open the Design tab and choose Paragraph Spacing, preview a choice, then click it.

Save after you format so you keep the look you chose.
