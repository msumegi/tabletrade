Quiz · Lesson 5 of 8

Folders, flags, and finding a message later

Choose an answer, then check it. Your score stays on this device.

Question 1 of 7

  1. In classic Outlook, Microsoft says you create a mail folder by:

    Classic Outlook: right-click in the left pane of Mail, then New Folder. New Outlook uses Create new folder.

  2. Two official ways to file a message in a folder are:

    Drag and drop, or Move on the ribbon (or right-click Move).

  3. When you select the flag icon on a message, Microsoft says:

    The flag turns red and the message becomes a to-do item.

  4. To add a date and time reminder to a flagged message, Microsoft says you can:

    Right-click the flag and choose Add Reminder.

  5. When a follow-up is finished, Microsoft says you can:

    Follow Up > Mark Complete turns the flag into a green checkmark.

  6. To find messages from one person, a useful search is:

    from: plus the address limits results to that sender.

  7. If a search list is very long and you still cannot see the message, Microsoft’s search page says to:

    Make the search more specific; Outlook returns a limited first set of results.
