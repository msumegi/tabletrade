Attachments and a professional tone

Choose an answer, then check it. Your score stays on this device.

Question 1 of 7

  1. Microsoft says you attach a file from the message window by choosing:

    Message > Attach File.

  2. To save an attachment you received, Microsoft says you can:

    Save As from the Attachments tab or the right-click menu.

  3. A professional signature should be:

    Microsoft asks for a simple, short, professional signature, free of graphics if possible.

  4. If you are angry about a workplace note, Microsoft says it is better to:

    Save a draft and return later; do not send while angry.

  5. An empty message that contains only an attachment is:

    Name the file in the body so the reader knows what to do.

  6. Microsoft says to use High Importance:

    Use High Importance sparingly.

  7. If a conversation has many messages and no resolution, Microsoft’s writing-advice page says you may want to:

    After more than about ten messages without a resolution, consider calling or meeting.
