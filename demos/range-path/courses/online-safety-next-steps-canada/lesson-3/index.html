Make your home router safer

Connecting to a trusted Wi-Fi network is covered in another course. This lesson is about the box at home that creates that network: the router.

The Cyber Centre says a router is hardware that creates a network for devices in a local area. A modem then connects that network to the internet. Some units combine both jobs and are still called routers. A poorly set-up router can be an attractive target.

Get Cyber Safe’s family guidance and the Cyber Centre’s router basics agree on several home steps:

  • Change the router’s username and password from the default settings. Also change the default password for the Wi-Fi network itself. Do not leave the password that was printed on the sticker if you can change it.
  • Set up a guest network for visitors and for smart devices such as a smart TV. That way you are not sharing your main password, and those devices are separated from your primary network.
  • If you can, place the router in a central spot in your home, away from windows. The Cyber Centre also says to restrict physical access to the device.

The Cyber Centre adds a few other basic measures: turn on strong Wi-Fi protection (it names WPA2 or the newer WPA3), change the default network name so the make and model are not obvious, and disable WPS (a convenience feature that can be attacked). Keep the router’s firmware up to date, and turn on automatic firmware updates if the model offers them. That is an update for the router itself, not the phone and computer updates taught in another course.

Skip advanced steps such as port filtering unless a technician is helping you. Start with the defaults, the guest network, and physical placement.
