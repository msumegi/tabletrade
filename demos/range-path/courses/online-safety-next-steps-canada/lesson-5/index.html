Back up the files you do not want to lose

Get Cyber Safe says you should treat important digital files the way you treat meaningful possessions: keep a safe copy. Your phone, computer, and tablet hold memories, documents, and personal files. Backing up means creating a copy and storing it securely so you do not lose those files if you lose a device, delete something by accident, or run into malicious software.

Choose a backup method that fits you:

  • Cloud storage keeps files on an online server so you can open them from another device when you have internet.
  • An external hard drive can back up files automatically with software, or you can copy them yourself.
  • A USB flash drive is portable: copy the files onto it and eject it safely when you are done.
  • Network attached storage (NAS) is a shared box for several devices on one network. Get Cyber Safe notes this as a useful option for a small business with many devices in one place.

Consider using two kinds of storage so one lost or stolen copy is not the only copy. Set a backup schedule. Some tools run automatically, but not all of them do. Set a reminder to check that the backup actually worked.

Protect backups with a strong password and turn on MFA when the service offers it. Get Cyber Safe’s family page also includes “regularly back up the data on your devices” in its housekeeping list.

This course does not recommend a brand of cloud storage or drive. Pick a method you can keep up, and test that you can open a file from the copy.
