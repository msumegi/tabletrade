Lesson 1 of 5

Plan a small site for your group

WordPress is software that can run a blog, a website, or a site that includes both. Official WordPress.org documentation says learning a few basics before you change things can save time.

This course is for people who already have a WordPress site, or who will be given a login by their council or community group. It does not tell you which company should host the site, and it does not walk through installation. Those choices belong to whoever looks after the technical side.

WordPress.org asks you to make a plan. For a community group, start with a short list of Pages — information that stays useful over time. The documentation gives examples such as About, Contact, and Events. You might also want a page that says who you are, when you meet, and how to reach you.

Then decide whether you also need Posts. Posts are dated items that, in a default setup, appear in reverse chronological order, like news or “what happened this month.”

Write the words for each page on paper first, in plain language. You do not need to design a new look yet. WordPress.org notes that a theme controls the appearance of the site — the framing and style of the content. You can leave the current theme alone until the words are in place.

This is not a course in building a page from HTML files. If you only need one simple file on your own computer, use the Range Path course on building a very simple web page instead.
