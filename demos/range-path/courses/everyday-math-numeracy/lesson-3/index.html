Lesson 3 of 5

Measure, compare, and estimate

The numeracy self-assessment includes taking simple measurements (for example length, weight, or temperature), making comparisons (taller or shorter, heavier or lighter, greater than or less than), recording time, estimating quantities (for example “I need approximately 20 copies”), and estimating measurements. It also lists measurement conversions, such as inches to centimetres or millilitres to litres.

You do not need special tools for every task. A kitchen scale, a wall clock, a vehicle display in kilometres, or a weather report in °C can all be measurement sources. When you must convert one unit to another, look up the official factor or use the scale already printed on the tool. This course does not invent conversion numbers.

Estimate when an exact number is not needed yet. If you need about 20 copies, you do not count them to the last sheet before you start — but you still check later if the exact count matters.

Compare two numbers before you decide. Which package is heavier? Which waiting time is shorter? Which total is greater?

Skills for Success says to judge whether a result is about the right size. If you estimate “about 20 minutes” for a five-minute walk you make every day, the estimate is probably too high. Adjust and try again.

Write down the unit (°C, kg, km, minutes) so other people can use your number.
