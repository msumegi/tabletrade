Files, folders, and finding what you saved

Choose an answer, then check it. Your score stays on this device.

Question 1 of 7

  1. A folder is best described as:

    A folder holds files.

  2. An official way to open File Explorer is:

    Taskbar, Start, or Windows key + E (Microsoft). Windows key + L locks the PC.

  3. Microsoft’s steps to move a file are:

    Microsoft: Cut, navigate, Paste.

  4. On many Android phones, Google says files usually live in:

    Google: Files app, or the manufacturer’s app.

  5. Downloads is often where:

    Downloads is a known folder for items you save from the internet.

  6. True or false: On a library computer you should delete any file you do not recognise.

    Delete only your own practice files; ask first on a shared machine.

  7. A useful file name is:

    A clear name is easier to search for.
