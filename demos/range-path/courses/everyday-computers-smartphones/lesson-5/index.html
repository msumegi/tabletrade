Join a network you already know

About 2 minutes to read, plus a short practice.

Wi-Fi is a wireless way to reach the internet through a nearby network. On many Android phones, Google’s steps (some of them only on Android 12 and up) are: open Settings, tap Network & internet, then Internet, then tap a listed network. Networks that need a password show a lock icon. After you connect, the network is “Saved,” and when you are nearby with Wi-Fi on, the phone can join it again automatically.

Google also describes a faster path: swipe down from the top of the screen, tap Internet, and select a network in the panel that appears. You can use that panel to switch networks quickly. To disconnect, Google’s path is Settings > Network & internet > Internet, then the Wi-Fi settings beside the connected network, then Disconnect. To forget a saved network, touch and hold it and tap Forget — useful if you joined the wrong name.

On Windows 11, Microsoft’s steps are: select the Network, Sound, or Battery icons on the taskbar to open quick settings; on the Wi-Fi quick setting, select Manage Wi-Fi connections; choose the network and select Connect; type the network password, then select Next. If you do not see the name you expect, Microsoft says you can refresh the network list. On Windows 10, the same Microsoft page says: select the Network icon on the taskbar (or the Up arrow if the icon is hidden), choose the network, select Connect, type the password, then Next, then Yes or No when asked whether the PC should be discoverable.

This course will never ask you to type a real Wi-Fi password into a practice screen. If you connect on a real device, type the key only in the real prompt, with a tutor nearby if you want company.

Read the name, and read the lock

About 1 minute to read, plus a short practice.

The most important check happens before you type anything: is this the network you meant to join? Names can look alike. “TownLibrary” and “TownLibrary_Free” are not automatically the same network. Get Cyber Safe says cyber criminals sometimes create fake or “evil twin” hotspots that sit in the same place or use a similar name to lure people. When you can, ask someone from the organisation that hosts the Wi-Fi for the real name before you connect.

A lock icon (on Android, Google says this marks a network that requires a password) is not the same as “this network is safe.” It only means you need a key to join. A café can have a lock and still be a public network that many people share. An open network with no lock is even easier for anyone nearby to join.

After you connect, Android can save the network and rejoin it later. That is handy at home. It is less handy if you saved a network you did not mean to trust. Forgetting the network (touch and hold, then Forget) clears that automatic join. On Windows, Microsoft also describes saved (“known”) networks in Settings.

If a device asks whether it should be discoverable (Windows 10’s Yes or No question), treat a public place as a place where you usually do not want other people’s devices to find yours. When you are unsure, ask a tutor rather than tapping Yes out of habit.

Keep the “before you connect” checklist nearby. It is a short list you can reuse in a library, a hall, or a café.

Public Wi-Fi is convenient, not private

About 1 minute to read, plus a short practice.

Get Cyber Safe says public Wi-Fi is flexible and can save mobile data, but unsecure public networks are not the safest option because anyone can connect — including people who might try to harm you. On the same network, someone may try to reach your device or listen in on traffic. They can also try to spread malware, especially to devices that are not kept up to date. That is one reason Lesson 6 spends time on updates.

Fake hotspots are the name-alike problem from Chapter 2. Ask staff for the official network name. If you are in a public Wi-Fi zone but you do not need the internet, Get Cyber Safe says to turn Wi-Fi off. Never use public Wi-Fi to open a bank account page or to make a purchase. If you use public Wi-Fi often, Get Cyber Safe says a virtual private network (VPN) can be a safer extra: it sends your traffic through a separate encrypted path. They note that many internet providers offer a VPN as a secondary service. This course does not recommend a brand.

Two more everyday habits: watch for shoulder surfers (people reading your screen), and prefer sites that protect the page itself. Get Cyber Safe says not to trust the wireless encryption on a public network alone. Look for a padlock icon at the start of the address bar. Many browsers, they note, no longer show the words HTTP, HTTPS, or www. The padlock is the sign to look for. You will practise that idea again in Lesson 7.

None of this is legal advice, and it is not a promise that a network is safe. It is a short list of official Canadian precautions so you can use Wi-Fi with fewer surprises.

Try it

About 1 minute to read, plus a short practice.

Use the “before you connect to Wi-Fi” checklist on a known network, with staff nearby if you are not at home:

  1. Confirm the real network name.
  2. Open the Wi-Fi list (Android Settings path or Windows taskbar path).
  3. Look for a lock icon if one appears.
  4. Connect only if you are allowed to, and type a password only in the real device prompt.
  5. Do not open banking or make a purchase on public Wi-Fi.

Wi-Fi — take-home steps

  • Android: Settings > Network & internet > Internet (some steps Android 12+)
  • Or swipe down and tap Internet
  • A lock icon means a password is required — not that the network is private
  • Windows 11: taskbar Network/Sound/Battery > Manage Wi-Fi connections > Connect > password > Next
  • Ask staff for the real network name; watch for look-alike hotspots
  • No banking or purchases on public Wi-Fi; turn Wi-Fi off when you do not need it
  • Never type a Wi-Fi key into this course
