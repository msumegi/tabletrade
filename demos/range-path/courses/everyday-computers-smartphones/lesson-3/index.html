Files, folders, and finding your work

A file is one piece of saved work, such as a letter, a photo, or a spreadsheet. A folder is a container that holds files (and sometimes other folders). Skills for Success includes storing and organizing digital information in a logical way using files, folders, and labels — for example, downloading a file into a folder on your computer.

On a Windows computer, File Explorer helps you find, open, organize, and manage files and folders. Microsoft’s help says you can open File Explorer from the taskbar or the Start menu, or by pressing the Windows logo key and the letter E.

Common folders you may see include Documents, Downloads, Pictures, Music, and Videos. Many apps save everyday files into one of these folders, which makes them easier to find later.

Habits that help:

  1. Give a file a clear name you will remember, such as rent-receipt-november rather than document1.
  2. Save related files in the same folder.
  3. Use the search box in File Explorer if you forget where a file went. Microsoft says you can search from File Explorer Home, or search inside a folder such as Downloads.
  4. To move a file, Microsoft’s File Explorer help says to select it, choose Cut, go to the new place, then choose Paste.

On a phone, files may sit in Photos, Files, Downloads, or inside an app. The idea is the same: know where you saved something.

Ask a tutor before you permanently delete a file you might still need.
