Question 1 of 8

  1. A sensible first check when a screen is dark is to:

  2. Windows key + L:

    Microsoft: lock with Windows key + L; apps stay open.

  3. If a phone is lost, Get Cyber Safe says to:

    Provider (deactivate / blacklist) and police.

  4. Get Cyber Safe says you should never:

    Do not recover stolen property yourself.

  5. If the screen is frozen on a shared computer, a calm step is to:

    Ask before signing out or forcing buttons; unsaved work can be lost.

  6. True or false: This course promises to repair any device that goes wrong.

    This is not a tech-support contract.

  7. A pop-up that shows a support phone number you did not ask for is a reason to:

    Ignore surprise numbers; use known contacts.

    Five everyday skills, no live secrets in the course.
