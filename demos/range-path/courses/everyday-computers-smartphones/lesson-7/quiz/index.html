Browsers, search, and deciding if a page is trustworthy

Choose an answer, then check it. Your score stays on this device.

Question 1 of 7

  1. A browser is:

    A browser opens websites.

  2. Google’s search help says that if you want a local place you should:

    Add the place name (Google Search help).

  3. Get Cyber Safe notes that many browsers no longer show:

    Look for a padlock instead (Get Cyber Safe).

  4. Chrome’s help lists a status called:

    Also Default (Secure) and Info or Not secure.

  5. If a text asks you to log in by tapping a link, Get Cyber Safe says you should:

    Never click a link in a suspicious message or send your password.

  6. True or false: A page that shows a secure connection is always the organisation you intended to visit.

    A secure connection does not prove identity; check the address.

  7. If you did not mean to open a page, a calm next step is to:

    Back, and do not type private details.
