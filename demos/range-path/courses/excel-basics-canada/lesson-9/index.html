Choose the cells — and a simple chart type

About 3 minutes to read, plus a short practice.

A chart is a picture of numbers that already live on the sheet. It does not invent new facts. If Wednesday is 7.5 hours in the grid, the bar or column for Wednesday should match 7.5. Microsoft's chart page says charts help you visualize data, and it starts with a plain instruction: select the data for the chart, then choose a chart.

Select the labels and the numbers together. For a week of hours, select A1:B8 — the Day header and values, and the Hours worked header and values. If you select only the numbers, the chart may show 1, 2, 3 instead of Mon, Tue, Wed. If you include the Total row (row 9) by accident, the total can dwarf the days and make the picture misleading. Select through Sunday only unless you truly want the total in the chart.

This course stays with everyday types. Microsoft describes column charts as a common way to show categories along the horizontal axis and values up the vertical axis — a good fit for hours by day. Pie charts show parts of one whole. Microsoft says to consider a pie when you have only one data series, none of the values are negative, almost none are zero, and you have no more than seven categories that really are parts of the same total. Five household amounts can make a pie; a week with two zero days is a weaker pie (those slices vanish) and a better column chart.

You do not need 3-D exploding pies, trendlines, or combination charts here. A flat column chart with a clear title is enough. Give the chart a title that names the list and reminds readers it is sample data, such as Hours worked — sample only.

Insert a recommended chart

About 2 minutes to read, plus a short practice.

On Windows desktop Excel, Microsoft's create-a-chart page lists this path:

  1. Select the data for the chart.
  2. Select Insert > Recommended Charts.
  3. Select a chart on the Recommended Charts tab to preview it.
  4. If you do not see one you like, select the All Charts tab.
  5. Select a chart, then select OK.

Microsoft also notes that you can select the data and press Alt+F1 to create a chart immediately, but it might not be the best chart for the data. Prefer Recommended Charts so you can preview first.

After the chart appears, click it. Extra chart tools show on the ribbon (names can include Chart Design). If a “Chart Title” box is sitting on the chart, click it and type your own title. Screens differ on Mac and on Excel for the web. Microsoft's web instructions still start the same way: select the range, go to the Insert tab, and choose a chart type under Charts. Recommended Charts may appear there for some Microsoft 365 subscribers. If Insert > Recommended Charts is missing, use Insert > Charts and pick a simple column chart.

Keep the chart on the same sheet as the data so you can see both at once and compare them. If you change Friday from 5 to 5.5, glance at the Friday column: it should grow. If it does not, you may have selected the wrong cells when you created the chart.

Another official path: Quick Analysis

About 2 minutes to read, plus a short practice.

Microsoft's basic-tasks page offers a second Windows desktop path with Quick Analysis (noted there in connection with Excel 2016):

  1. Select the cells that contain the data you want to show in a chart.
  2. Click the Quick Analysis button in the bottom-right corner of the selection.
  3. Click the Charts tab, move across the recommended charts to preview them, and then click the one you want.

Excel shows different charts in that gallery depending on what it recommends for your data. Preview before you click. The chart still uses only the cells you selected, so the same caution applies: include labels, leave out a total row unless you want it.

If you do not see Quick Analysis, that is fine — use Insert > Recommended Charts or Insert > Charts. Do not install extra software to chase a button. Library computers especially may have a slightly older ribbon.

Once you have a chart, look at it with the same common-sense check you used for totals. Is Wednesday the tallest hours column (7.5)? Is fuel the largest household slice or column (80.00)? If the picture disagrees with the grid, the selection or the chart type is wrong, not the universe. Delete that chart (click it and press Delete) and make a new one from the correct cells. Deleting a chart does not delete the numbers on the sheet.

Give every practice chart an honest title. Household amounts — sample only is clearer than Chart 1. Anyone who sees a screenshot later should know these are not a real family's bills.

Worked example 1. A column chart of the sample week

About 2 minutes to read, plus a short practice.

Worked example 1. A column chart of the sample week

Problem

On the Hours sheet, select A1:B8.

Steps

  1. Choose Insert > Recommended Charts, pick a clustered column preview that shows Mon through Sun, and click OK.
  2. Title it Hours worked — sample only .
  3. Check the picture against the grid: Wednesday should be the tallest column at 7.5; Thursday and Sunday should show no bar or a flat bar at zero; Monday should sit at 6.

Result

If the total 25.5 appears as an eighth giant column, you included B9 — delete the chart and select only A1:B8.

Worked example 2. Household amounts as a simple picture

About 2 minutes to read, plus a short practice.

Worked example 2. Household amounts as a simple picture

Problem

Select the item names and the amounts on the Household sheet (A1:A6 and C1:C6, or A1:C6 if the preview still makes sense).

Steps

  1. Insert a recommended column chart, or a pie if Microsoft's preview looks clean — five positive values, no zeros, one series.
  2. Title it Household amounts (CAD) — sample only .
  3. Fuel at 80.00 should dominate; bread at 3.29 should be the smallest.
  4. This is not a budget report and not a real household's spending.

Result

It is the same five practice rows you have used since Lesson 1.

Try it

About 2 minutes to read, plus a short practice.

  1. Create a column chart from Hours A1:B8. Leave the Total row out.
  2. Give it the title Hours worked — sample only.
  3. Create a second chart from the Household items and amounts.
  4. Change Wednesday's hours from 7.5 to 8 and see whether the Wednesday column grows. Then put 7.5 back.
  5. If a chart looks wrong, delete the chart (not the data) and make it again.

Optional discussion (council study group)

About 2 minutes to read, plus a short practice.

Would a hall committee rather see the week's hours as a table, a column chart, or both? What title would stop someone from treating sample numbers as official records?

A basic chart — take-home steps

  • Select labels and numbers together (Hours: A1:B8, not the Total row)
  • Insert > Recommended Charts, preview, then OK
  • If Recommended Charts is missing, use Insert > Charts
  • Quick Analysis > Charts is a Windows desktop extra
  • Give the chart an honest title, such as Hours worked — sample only
  • A pie chart fits one series of parts of a whole, with almost no zeros
