Make a sheet easier to read

Plain numbers are useful. A little formatting makes a sheet easier to scan.

Borders (Microsoft):

  1. Select the cell or range you want to outline.
  2. On the Home tab, in the Font group, click the arrow next to Borders, and choose a style.

Shading (fill colour):

  1. Select the cells.
  2. On the Home tab, in the Font group, click the arrow next to Fill Color, and pick a colour.

Use light colours for titles so the text stays readable.

Number formats: Microsoft says you can add a format such as currency, percentages, or dates so different kinds of numbers are easier to tell apart.

  1. Select the cells that have numbers.
  2. Click the Home tab, then the arrow in the General box.
  3. Pick a number format. If you do not see the one you want, click More Number Formats.

Choose a format that matches how you write money or dates in Canada. If you are not sure which currency or date style to pick, ask a tutor. This course does not tell you which format a workplace or the CRA requires.

You can also select a block of cells by clicking the first cell and dragging to the last cell. Microsoft notes you can hold Shift and use the arrow keys to select with the keyboard.

Save your work after you format (Lesson 5) so you do not lose the layout.
