Format cells so a list is easy to read

Choose an answer, then check it. Your score stays on this device.

Question 1 of 7

  1. Number formats change:

    Display changes; values stay the same.

  2. To add a border, Microsoft's path is:

    Home > Font > Borders arrow.

  3. Fill Color is found:

    Home > Font > Fill Color.

  4. A sensible format for Household amounts in CAD is:

    Currency, or Number with two decimals and CAD in the header.

  5. If you apply Percentage to a cell that contains 5.49 (dollars):

    Percentage is for rates, not dollar amounts.

  6. After you apply Currency to 5.49, the formula bar still shows:

    The stored value remains 5.49.

  7. Calm formatting for a header row is:

    Light, readable formatting with labels that work without colour.
