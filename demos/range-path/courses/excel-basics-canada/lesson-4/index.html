Format for readers — not for decoration

About 3 minutes to read, plus a short practice.

A list is easier to trust when other people can see where one row ends and the next begins, and when money looks like money. Formatting is that extra clarity. Microsoft's basic-tasks page covers three everyday tools you will use here: cell borders, cell shading (fill colour), and number formats such as currency, percentages, or dates.

Number formats change how a value is displayed. They do not change the value itself. Microsoft's number-format help says this plainly: formats only change how numbers appear and do not affect the values. If cell C2 contains 5.49 and you apply a Currency format, the cell may show something like $5.49, but Excel still stores 5.49 for any later formula. That is why you typed plain numbers in Lesson 3.

Good formatting is calm. A bold-looking header row (a light fill and a bottom border) helps. A thin border around the data block helps. Matching decimal places in a money column helps. Rainbow colours, a different fill on every row, or a tiny font do not help. If you use colour, use it as a backup to clear labels, not as the only way to tell categories apart — a print-out or a photocopy may lose the colour.

You do not need to format empty rows below the list. Format the cells you are actually using, including the header row. If you add a new row later, you can copy the format from a neighbour cell or select the new cells and apply the same border and number format again.

Borders and fill colour

About 2 minutes to read, plus a short practice.

Microsoft's steps for a border are:

  1. Select the cell or range you want to add a border to.
  2. On the Home tab, in the Font group, click the arrow next to Borders, and then click the border style you want.

A useful style for a small list is All Borders around the block that has data, or a bottom border under the header row. Select a range by clicking the first cell and dragging to the last cell. To use the keyboard, Microsoft says to hold down Shift while you press the arrow keys.

Microsoft's steps for shading are:

  1. Select the cell or range.
  2. On the Home tab, in the Font group, choose the arrow next to Fill Color, and then under Theme Colors or Standard Colors, select the colour you want.

A pale fill on the header row (A1:C1 on Hours, or A1:D1 on Household) is enough. Avoid very dark fills that hide black text. If you colour a cell by mistake, open Fill Color again and choose No Fill if that option appears, or pick white.

Select first, then click the tool. If you click Borders or Fill Color with only one cell selected, only that cell changes. If you meant to format the whole list, select the full block and apply the style again.

Border menus often list more than one style (for example a bottom border, outside borders, or all borders). For a small everyday list, all borders — lines around and between the cells — usually make the grid easiest to follow on screen and on paper. If the result looks too heavy, choose a simpler style and try the range again.

Number formats for hours and Canadian dollars

About 2 minutes to read, plus a short practice.

To distinguish types of numbers, Microsoft says to add a format such as currency, percentages, or dates:

  1. Select the cells that have the numbers you want to format.
  2. Click the Home tab, and then click the arrow in the General box.
  3. Pick a number format. If you do not see the one you want, click More Number Formats.

The number-formats page lists the same idea on the Home tab Number drop-down, and it names formats you will meet most: General (the starting point), Number (you can set decimal places), Currency (shows the default currency symbol), Accounting (also for money, and it lines up symbols and decimal points), Date, and Percentage (multiplies the display by 100 and adds a % sign). Percentage is powerful — only use it when the cell already holds a rate such as 0.05, not when it holds 5.49 dollars.

For the Hours sheet, Number with one decimal place is a sensible choice for column B so 6 and 7.5 line up. For the Household sheet, select C2:C6 and choose Currency. On a computer set up for Canada, the symbol is often $. If you see a different symbol, the computer's default currency is different; you can open More Number Formats and look for a currency choice you recognise, or leave the amounts as Number with two decimal places and keep Amount (CAD) in the header. Either way, this is display only. It is not tax help.

Do not apply Percentage to a money column. Do not apply Currency to the hours column. Match the format to what the column means.

Worked example 1. Make the Hours list easier to scan

About 2 minutes to read, plus a short practice.

Worked example 1. Make the Hours list easier to scan

Problem

On the Hours sheet, select A1:C1 and apply a pale Fill Color from Home > Font. Then select A1:C8 and choose a full border style from Home > Font > Borders. Select B2:B8 and, from Home > the General arrow, choose Number. If a dialog lets you set decimal places, choose 1 so 6.0 and 7.5 line up. Leave column C (Notes) as General or as text — those cells are words, not amounts.

Result

Stand back and look at the sheet. You should be able to run a finger down Wednesday's row and see Wed, 7.5, and Market stall without losing the line. That is enough formatting for an everyday hours list.

Worked example 2. Show household amounts as money

About 2 minutes to read, plus a short practice.

Worked example 2. Show household amounts as money

Problem

On the Household sheet, select C2:C6. On the Home tab, click the arrow in the General box and pick Currency. The sample values 5.49, 3.29, 80.00, 45.00, and 25.00 should now display as currency. Add a simple border around A1:D6 if you like, and a pale fill on A1:D1.

Result

Check that column D (Category) is still plain text: Groceries, Vehicle, Farm, Household. Category labels should not receive a currency format. If you formatted too many columns by mistake, select the text cells and set them back to General.

Try it

About 2 minutes to read, plus a short practice.

  1. On Hours, apply a header fill, borders around the data, and a Number format on the hours.
  2. On Household, apply Currency to Amount (CAD) and a header fill.
  3. Click C2 on Household and read the formula bar. You should still see the underlying number (5.49), even if the cell displays a dollar sign.
  4. Do not apply Percentage to the amount column.

Optional discussion (council study group)

About 2 minutes to read, plus a short practice.

What makes a printed list hard to read at a hall meeting — faint pencil totals, missing headers, or crowded numbers? Which one formatting change would help most?

Borders, fill, and number formats — take-home steps

  • Select the cells first
  • Home tab, Font group: Borders arrow, then a style
  • Home tab, Font group: Fill Color arrow, then a pale colour
  • Home tab, arrow on General: Currency, Number, Date, or More Number Formats
  • Formats change how numbers look, not the stored values
  • Do not use Percentage on a money column
