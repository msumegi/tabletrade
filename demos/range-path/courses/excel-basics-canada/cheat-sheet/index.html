Cheat sheet

Sample steps only. Use the browser print dialog to save a PDF.

Lesson 1. Workbook, sheet, and cell — take-home steps

  • A workbook is the Excel file
  • A sheet is one grid inside that file
  • A cell is one box, named by column letter and row number
  • Cell A1 is column A, row 1 — the top-left cell on a new sheet
  • This course stays with everyday lists, not advanced analysis, tax, or payroll advice

Lesson 2. Open a workbook and move around — take-home steps

  • File > New > Blank workbook starts an empty file
  • The name box shows the active cell, such as A1
  • The formula bar shows what is inside that cell
  • Enter (Return on a Mac) usually moves down
  • Tab usually moves right

Lesson 3. Enter text, numbers, and dates — take-home steps

  • Click a cell, type, then press Enter or Tab
  • Keep one kind of information in each column
  • Type numbers without extra words (put hours or CAD in the header)
  • Do not leave a trailing space after a number
  • A typed 0 is not the same as a blank cell
  • Home > arrow on General > Date (or More Number Formats) changes how a date looks

Lesson 4. Borders, fill, and number formats — take-home steps

  • Select the cells first
  • Home tab, Font group: Borders arrow, then a style
  • Home tab, Font group: Fill Color arrow, then a pale colour
  • Home tab, arrow on General: Currency, Number, Date, or More Number Formats
  • Formats change how numbers look, not the stored values
  • Do not use Percentage on a money column

Lesson 5. Simple formulas — take-home steps

  • A simple formula starts with =
  • Add with +, subtract with -, multiply with *, divide with /
  • You can tap cells instead of typing their addresses
  • Multiplication and division happen before addition and subtraction
  • Microsoft’s example =5+2*3 gives 11, not 21
  • Read the formula bar to see the instruction, not only the result

Lesson 6. AutoSum and AVERAGE — take-home steps

  • AutoSum usually goes in the cell under a column of numbers
  • Home > AutoSum (Editing group), or Formulas > AutoSum
  • AutoSum writes a SUM formula such as =SUM(B2:B8)
  • Formulas tab > arrow next to AutoSum > Average writes AVERAGE
  • Check the highlighted range before you press Enter
  • Zeros do not change a sum, but they pull an average down
  • Compare the result with a rough mental estimate

Lesson 7. Fill and lock a cell — take-home steps

  • Drag the fill handle (small square) to copy into adjacent cells
  • Or select the formula plus the empties and use Home > Fill > Down (Ctrl+D)
  • Relative references such as A2 shift when you copy them
  • An absolute reference such as $H$1 stays put
  • Use $ when one sample rate should apply to every row
  • A sample extra-rate column is practice math, not tax advice

Lesson 8. Sort, filter, and a simple table — take-home steps

  • Include every column of the list before you sort, so rows stay together
  • Data tab > Sort opens the Sort dialog
  • Data tab > Filter puts arrows on the headers
  • Clear Select All, then tick only the values you want to see
  • Filter hides rows; it does not delete them
  • Home > Format as Table: choose a style, confirm the range, tick headers, OK

Lesson 9. A basic chart — take-home steps

  • Select labels and numbers together (Hours: A1:B8, not the Total row)
  • Insert > Recommended Charts, preview, then OK
  • If Recommended Charts is missing, use Insert > Charts
  • Quick Analysis > Charts is a Windows desktop extra
  • Give the chart an honest title, such as Hours worked — sample only
  • A pie chart fits one series of parts of a whole, with almost no zeros

Lesson 10. Save, print, and share with care — take-home steps

  • Save or Ctrl+S updates a file you have already saved
  • File > Save As is for the first save, a new place, or a copy
  • AutoRecovery is not a substitute for saving yourself
  • File > Print or Ctrl+P — look at the preview before you print on a shared lab printer
  • File > Save As or Save a Copy > PDF (*.pdf) exports a snapshot
  • A PDF is not a guarantee that no one can edit it, and it still holds what you typed
  • Open every sheet tab (and clear filters) before you share
