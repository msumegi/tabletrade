Question 1 of 7

  1. To start a new empty Excel file, Microsoft's basic path is:

    File > New > Blank workbook, from Microsoft's basic-tasks page.

  2. Cell D10 is:

    The letter is the column; the number is the row.

  3. After you type in a cell, Tab usually moves:

    Tab moves to the next cell to the right.

  4. After you type in a cell, Enter (Return on a Mac) usually moves:

    Enter moves down.

  5. The name box shows:

    The name box shows the active cell's address.

  6. Sheet tabs at the bottom of the window:

    Tabs switch sheets inside the same workbook.

  7. Scrolling the window:

    Scrolling changes your view; clicking a cell after you scroll is what changes the active cell.
