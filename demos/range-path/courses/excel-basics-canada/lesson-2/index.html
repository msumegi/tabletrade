Enter data in cells

Entering data means typing information into cells so Excel can use it later.

Microsoft’s steps:

  1. Click an empty cell. On a new sheet, try A1.
  2. Type text or a number.
  3. Press Enter or Tab to move to the next cell.

Enter usually moves you down to the cell below. Tab usually moves you right to the next column. If you make a mistake, click the cell again and type the correction, or edit what you see.

A simple practice table (sample data only):

AB
1ItemAmount
2Fuel80
3Feed45
4Supplies25

Type the words in column A and the numbers in column B. Keep one kind of information in each column. That makes adding and sorting easier later.

Tips:

  • Click once to select a cell before you type.
  • If you start typing in the wrong cell, click the cell again and type the correction.
  • Do not type a space after a number if you want Excel to treat it as a number.
  • Use sample amounts in this course. Do not enter real banking passwords or anyone’s private pay details into a shared computer.

When a cell is selected, you can also see and edit its contents in the formula bar near the top of the window (you will use this more in Lesson 4).
