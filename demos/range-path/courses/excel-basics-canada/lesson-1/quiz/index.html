Question 1 of 7

  1. An Excel file is called a:

    Microsoft calls an Excel file a workbook.

  2. Cell B3 is:

    The letter is the column; the number is the row.

  3. A cell can hold:

    Microsoft's basic-tasks page says cells can contain numbers, text, or formulas.

  4. Skills for Success name Digital as a skill that includes:

    The Skills for Success Digital description uses “create spreadsheets” as an example and names Excel as a common tool.

  5. In the practice Hours list, a 0 for Thursday means:

    A typed 0 is information. A blank cell is not the same as zero.

  6. This course will teach you to:

    This is a basics course, not MOS, college credit, or tax training.

  7. Dollar amounts and any extra-rate column in this course are:

    Sample money figures are examples only.
