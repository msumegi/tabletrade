Cells, rows, and columns

About 8 minutes to read, plus a short practice.

Microsoft Excel is a program for lists and numbers. Microsoft’s basic-tasks guide says Excel works well for simple calculations and for tracking many kinds of information. The key is a grid of cells. Cells can hold numbers, text, or formulas (instructions that calculate). You group cells in rows and columns so you can add, sort, filter, and later make charts if you want to.

Excel files are called workbooks. Each workbook has one or more sheets (also called spreadsheets). You can add more sheets, or start a new workbook when you want to keep information separate.

Cell addresses

About 7 minutes to read, plus a short practice.

Each cell has an address made from its column letter and row number. Cell A1 is column A, row 1 — the top-left cell on a new sheet.

People in Canada use spreadsheets for many everyday jobs: hours worked, a small expense list, a class attendance sheet, or a farm or household inventory. This course uses Canadian spelling and simple examples. It will not tell you how to file taxes or choose a bookkeeping system.

If Excel is not on the computer in front of you, ask your adult learning council which version they have, or whether you can use Excel for the web with a sign-in they approve. Do not buy software because this lesson mentioned it.
