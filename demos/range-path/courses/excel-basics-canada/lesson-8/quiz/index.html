Sort, filter, and a simple table

Question 1 of 7

  1. A safe habit before sorting Amounts is:

    Keep whole rows together.

  2. The Sort dialog Microsoft describes is opened from:

    Data > Sort.

  3. After Data > Filter, you choose which rows to see by:

    Header arrow, clear Select All, tick values, OK.

  4. Filtered rows that do not match are:

    Hidden, not deleted.

  5. Home > Format as Table requires you to:

    Style, range, headers, OK.

  6. Quick Analysis > Tables > Table is:

    Documented in Basic tasks; not always visible.

  7. This basics course does **not** ask you to build:

    PivotTables and Power Query are beyond this intro.
