Save the workbook

About 10 min

Saving puts your workbook in a file so you can close Excel without losing the work.

Microsoft’s basic steps:

  1. Click the Save button on the Quick Access Toolbar, or press Ctrl+S. If you have saved this file before, you are done.
  2. The first time, choose Save As, pick a location, browse to a folder, type a name in the File name box, and click Save.

A clear name helps you find the file later, such as hours-november or expense-list-practice. Save it in a folder you know, such as Documents (see the Everyday Computers course for File Explorer).

Save often while you work. Microsoft also describes AutoRecovery, which can keep a backup if something goes wrong, such as a power cut. AutoRecovery is not the same as you saving the file yourself, so do not rely on it alone.

Print or preview

About 8 min

To print (Microsoft):

  1. Click File, then Print, or press Ctrl+P.
  2. Preview the pages with the Next Page and Previous Page arrows.
  3. If the layout looks wrong, you can change margins or page breaks.
  4. Click Print.

Preview first so you do not waste paper. If you are on a shared learning-centre printer, ask staff which printer to pick.

When you finish, close the file. You can open it later from File Explorer or from File > Open in Excel.
