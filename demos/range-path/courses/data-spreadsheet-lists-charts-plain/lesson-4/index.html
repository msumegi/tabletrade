Read a simple chart

Statistics Canada says data visualization is the graphical representation of information and data. Charts, graphs, and maps can make trends and patterns that are hidden in a large set of numbers easier to understand. The brain often absorbs visual information quickly, so a picture of the data can help — if it is the right picture.

You do not need to create a chart in spreadsheet software to read one.

A few common types, from Statistics Canada’s introduction:

  • A bar chart is useful when you want to compare different groups. Taller or longer bars usually mean a larger number for that group.
  • A line graph is a good way to show how something changes over time.
  • A pie chart shows the composition of a whole, or how parts add up to 100%.
  • A table can show many categories and provide more detail and precision than many pictures.

When you read a chart, start the same way you start a table: read the title, check what each axis or slice represents, look at the units, and look for a source and date. Then ask what the picture is trying to compare, show over time, or break into parts.

A chart can make a pattern clear, but it can also hide detail. If you need an exact number, a table is often more precise. If two bars look almost the same height, do not guess — go back to the numbers if they are given.

This course does not teach you which Excel button makes a chart. It teaches you to read the chart in front of you.
