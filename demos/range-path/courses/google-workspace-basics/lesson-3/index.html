Create a Google Doc

Google Docs is the word-processing app in Google Workspace. You can write a letter, a notice, or a short report and work on it with other people later.

Google’s “Create, view, or download a file” page says:

  1. On your computer, open a Google Docs (or Sheets, Slides, Forms, or Vids) home screen. For a document, that home screen is docs.google.com.
  2. Click Create.

A new file is automatically named Untitled document. To rename it:

  1. Click the name at the top of the file.
  2. Type a new name.
  3. Press Enter.

When you are online, Google automatically saves your changes as you type. You do not need a Save button. If you are not connected to the internet, Google describes optional offline access — set that up only on a device you own, not on a public computer (see Google’s Drive and Docs help for those steps if you need them).

You can also download a copy: open the file, click File, then Download, and choose a file type. That is useful if someone needs a file they can open without Google Docs.

Type a short practise notice, such as “Community kitchen volunteers meet Thursday.” Use Canadian spelling. This lesson is not Microsoft Word training; if you need Word buttons, see the Range Path Word basics course.

If a file warning appears about phishing or malware, Google says to use caution. Do not ignore a warning just to finish a class task.
