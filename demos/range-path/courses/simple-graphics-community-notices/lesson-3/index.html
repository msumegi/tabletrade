Add and format text in a simple design tool

You can build a notice in Word or PowerPoint if that is what you already use. Many community groups also use Canva, an online design tool, to make posters and flyers. This lesson uses Canva’s official Help pages as one example. The same habits — large text, strong contrast, and few words — apply in any tool.

Canva Help says you can format text in many design types, including posters. After the words are on the page:

  1. Select the text.
  2. On the toolbar, select the font name, then choose a font.
  3. Select Font size and pick a size, or use the plus and minus buttons.
  4. Select Text color and choose a colour with strong contrast against the background.
  5. Use Bold for a short heading if you need it. Use italics and underline sparingly.

Filter fonts if you need to, including by language. Choose a simple sans-serif font that matches the guidance in Lesson 2, not a decorative font that is hard to read.

Keep the layout simple. Leave space around the edges. Put the event name first and largest, then the date, time, and place, then any extra details and a contact line.

Buttons and menus can change. If you cannot find a control, open Canva’s live Help page rather than guessing. You do not need a paid plan to practise with your own words and free elements. This course does not sell or endorse a paid upgrade.
