Create your first HTML file

MDN walks beginners through a first file called index.html. You can make a folder on your computer, create that file, and type a small page. Then open the file in your web browser to see it.

A basic page has this kind of structure (this sample is original wording for a community page, not copied from MDN’s demo text):

<!doctype html> <html lang="en"> <head> <meta charset="utf-8"> <title>Community supper</title> </head> <body> <h1>Community supper</h1> <p>Friday at 6:00 p.m. at the hall.</p> </body> </html>

MDN explains the main pieces:

  • <!doctype html> tells the browser this is an HTML page.
  • <html> wraps the whole page. The lang attribute sets the main language. Use en or fr (or en-CA) to match your words.
  • <head> holds information that is not the main story on the page, such as the character set and the title.
  • <meta charset="utf-8"> helps the browser show letters and accents correctly.
  • <title> is the name that appears in the browser tab.
  • <body> holds what people see: headings, paragraphs, pictures, and links.

Type carefully. A missing > or a forgotten closing tag can change how the page looks. Save the file, then open index.html in your browser. You should see your heading and paragraph. If you do not, compare your file with the structure above.

You have now made a real web page on your computer. That is the goal of this lesson.
