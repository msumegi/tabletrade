Lesson 4 of 5

Headings, paragraphs, and lists

Once the file opens, add more of your own words using the elements MDN teaches.

Headings mark titles and subtitles. HTML has six heading levels, from <h1> to <h6>. MDN says people often use only three or four levels. Use <h1> for the main title of the page. Use <h2> for a section under that title. Do not skip around without a reason.

Paragraphs go in <p> ... </p>. Put each short paragraph in its own pair of tags.

Lists need two kinds of tags. For a list where order does not matter, such as what to bring, use an unordered list:

<ul> <li>Your own mug</li> <li>A warm coat</li> </ul>

<ul> starts the list. Each <li> is one item. For a list where order does matter, such as steps, use <ol> instead of <ul>. The browser will number those items for you.

After each change, save the file and refresh the browser (or open the file again). That is how you check your work.

Keep the page short. A heading, two or three paragraphs, and one list is plenty for this course. You are practising structure, not filling a long report.

If something does not show up, look for a tag you opened but did not close.
