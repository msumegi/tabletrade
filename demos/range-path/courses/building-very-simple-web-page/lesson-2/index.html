What HTML is

HTML stands for HyperText Markup Language. MDN says it is the code used to structure a web page and its content. HTML is a markup language: you wrap pieces of text in elements so the browser knows what each piece is — a heading, a paragraph, a list, and so on.

Most HTML elements have three parts:

  • an opening tag, such as <p>
  • the content (the words)
  • a closing tag, such as </p>

Together they make an element: <p>Friday supper at the hall.</p>. The letter p stands for paragraph.

Some elements also have attributes. An attribute adds extra information inside the opening tag. You will use attributes later for links and pictures.

If you type a list of words with no HTML, the browser may show them all in one block. When you wrap them in the right elements, the browser can show a paragraph and separate list items.

HTML can also make a word into a link, place an image on the page, or build a table. This course stays with the basics: headings, paragraphs, lists, one link, and one image.

You do not need special paid software. A plain text editor that can save a file, plus a web browser, is enough. Save the file with a name that ends in .html.

This is not a secret language for experts only. It is a set of labels you put around your own words.
