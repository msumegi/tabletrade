# Range Path

Hidden demo at `/demos/range-path/`. It stays `noindex`, unlinked from the public homepage, and out of any sitemap.

Courses are separate pages: catalogue, course, lesson, quiz, and certificate. Progress and quiz scores stay on the device. The final quiz pass mark is 70%. A pass opens a sample completion certificate.

## Add a course

From this folder:

```bash
node tools/md-to-course.mjs path/to/course.md --before email-online-safety --short "Short name" --nav "Nav"
node tools/build-pages.mjs
```

`--before email-online-safety` puts the new course after the newer courses and before the original Email, SIN, and Winter courses. Use `--after some-slug` when it belongs beside a particular course. Writing a Simple Grant Application sits immediately after Project Management Basics.

Workplace Writing may later gain a short spelling section. Add that as another lesson object in `data/courses/workplace-writing-grammar-canada.json`, then rebuild. Keep it in that same file.

The converter writes `data/courses/<slug>.json` and inserts the registry line. It keeps the lesson text, official links, and quiz answers from the file. It does not invent facts. If a lesson has no quiz, it writes true/false questions from that lesson’s own sentences and prints a warning. Then edit `shortTitle` or `navLabel` in `data/registry.json` if the labels need a tweak, and run the build again.

Set `"extra": true` and `"featured": false` on a registry entry for a demo extra. Extra courses stay available, are listed after the main courses, and are not shown on the home page. Registry order is the catalogue order. How to Learn Online sits after the first four courses because it is a starter for taking an online course.

The registry drives the home page, catalogue, course pages, quizzes, progress, and certificates. Edit the JSON, not the generated HTML. `assets/catalogue.js` is generated by the build.

Check links, the footer disclaimer, `noindex`, and quiz answers with:

```bash
node tools/check-demo.mjs
```

## What the converter keeps back

These stay in the JSON for authors and are not shown to learners:

- The disclaimer at the top of a source file. Every learning page already shows the existing Range Path disclaimer once, in the footer.
- “About N words” lines.
- “Content notes for builders”.

The certificate uses the source line that starts with “It is not…”.
