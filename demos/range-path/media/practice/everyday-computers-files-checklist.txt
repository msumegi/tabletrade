File-and-folder practice checklist
Sample only. Do not type a password.

1. On a computer, open File Explorer. On a phone, open the Files app (or the name the phone maker uses).
2. Find Documents, Downloads, or a folder a tutor showed you.
3. Save a practice note with a name you can search for later, such as practice-note.
4. Close it, then find it again by that name.
5. On a shared computer, do not delete files you did not create. Ask a tutor first.
